# Project Atlas — Initial Context

Welcome to Project Atlas.

Before generating any code, read this context carefully.

## About the Project

Atlas is a digital platform dedicated to preserving and organizing the greatest football goals in history.

It is not:

- A news website
- A blog
- A social network

Atlas is a structured and searchable football archive.

The project follows an incremental development process.

Every implementation must respect the official project documentation available in the `/docs` folder.

## Development Principles

Always prioritize:

- Simplicity
- Reusable components
- Mobile First
- Responsive Design
- Clean architecture
- Maintainable code

Never implement features outside the current sprint.

Never invent business rules.

If information is missing, use placeholders instead of assumptions.

---

## Working Model

The development cycle is:

Planning

↓

Implementation

↓

Technical Review

↓

Approval

↓

Git Commit

↓

Next Sprint

Only one sprint is active at a time.

---

## Important

Do not redesign the project.

Do not change the architecture.

Do not rename routes.

Do not create features outside the sprint.

Wait for the sprint instructions before generating code.
