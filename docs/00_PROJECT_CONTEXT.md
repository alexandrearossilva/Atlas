# About Atlas

Atlas is a football platform dedicated to organizing the greatest goals in football history.

The platform will connect:

- Goals
- Players
- Clubs
- Competitions
- Rankings

The long-term objective is to become the largest organized football goal database available on the internet.

The MVP must remain simple, clean and highly maintainable.

# Development Principles

Always follow these principles.

• Reuse components whenever possible.

• Responsive Design.

• Clean Architecture.

• Low coupling.

• High readability.

• Never invent business rules.

• Never implement functionality outside the sprint.
